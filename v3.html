Cluster Suitability Framework

A modular scoring tool to prioritise ERW and biochar deployment zones across Indian agricultural clusters. Rate each criterion on a 1 (poor) to 5 (excellent) scale, or auto-fetch open-source data using cluster coordinates.

Cluster Identification

Latitude and longitude mark the cluster centroid. Radius defines the cluster extent — the fetch will describe the area accordingly. A radius of 25–75 km suits most district-level clusters.

Auto-fetch uses an AI model with web search to pre-fill ratings from soil, climate, geological and agricultural open-source datasets. Parameters with no available data are flagged for manual input.  Get OpenRouter key
